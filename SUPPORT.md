# Support

Alpha Desk is pre-release software and does not yet provide a runnable desk application or production support commitment.

For repository questions:

- use GitHub Discussions when that feature is enabled;
- use an issue for a reproducible non-sensitive bug or a scoped feature proposal;
- include the exact commit, operating system, tool versions, command, expected result, and sanitized output;
- consult [docs/STATUS.md](docs/STATUS.md) before reporting a planned capability as a defect.

Do not post credentials, wallet labels, private data, proprietary feed content, internal infrastructure, or private alpha in public support channels. Use [SECURITY.md](SECURITY.md) for sensitive reports.

RSI Tech can be contacted at `info@rsitech.ai` for repository stewardship questions. No response-time or production-operations SLA is offered before a supported release exists.
