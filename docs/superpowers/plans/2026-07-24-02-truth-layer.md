# Stage 1 Truth Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Capture complete Hyperliquid source evidence durably, convert it into a contiguous and versioned canonical event log, detect gaps and divergence, archive immutable evidence, and publish idempotent operational streams.

**Architecture:** `hl-capture` owns asynchronous source adapters and append-only spooling. A deterministic canonicalizer converts byte-preserving `SourceObservation` values into ordered `BlockEnvelope` and `CanonicalEventEnvelope` values, while a sequencer enforces continuity and quarantines conflicts. Parquet is the immutable archive; NATS JetStream is a replayable operational bus, not the source of truth.

**Tech Stack:** Rust 1.97.1, Tokio, Bytes, Prost, CRC32C, BLAKE3/SHA-256, Arrow/Parquet, async NATS/JetStream, RocksDB only for small capture cursors if required, `tracing`, Proptest, cargo-fuzz, MinIO/S3-compatible archive, systemd.

## Global Constraints

- Stage 0 tag `stage-0-foundations` and `docs/stage-gates/stage-0-foundations.md` must verify before this plan begins.
- The approved source of truth is `docs/superpowers/specs/2026-07-24-hyperliquid-alpha-desk-design.md` at tag `spec-v1.0.0`.
- Canonical state is never mutated by provisional observations.
- Source payload bytes or a lossless content-addressed reference are retained for every observation.
- Ingestion time is never used as a canonical tie-breaker when protocol order is available or derivable.
- A stable `EventId` with a different content hash is a critical divergence, never an update.
- Unknown source variants are quarantined and alarmed; they are never silently skipped.
- Capture acknowledges upstream progress only after the source observation is durable in the local spool.
- Canonical publication occurs only after archive durability and continuity policy pass.
- NATS delivery is at least once; every consumer-facing message carries a deduplication ID.
- V1 contains no execution capability, credentials, or signer access.
- Every task follows TDD and ends in a focused commit.

- [ ] **Step 2: Implement the stable EventId algorithm**

```rust
pub fn compute_event_id(input: &EventIdentityInput<'_>) -> EventId {
    let mut hasher = blake3::Hasher::new_derive_key("hyperliquid-alpha-desk/event-id/v1");
    hasher.update(input.chain_id.as_bytes());
    hasher.update(&input.block_height.to_be_bytes());
    hasher.update(input.transaction_identity.as_bytes());
    hasher.update(&input.canonical_event_index.to_be_bytes());
    hasher.update(input.event_kind.stable_name().as_bytes());
    hasher.update(&input.schema_major.to_be_bytes());
    EventId::new(format!("evt_{}", hasher.finalize().to_hex())).expect("non-empty")
}
```

```rust
pub struct ArchiveReceipt {
    pub manifest_id: ManifestId,
    pub block_height: BlockHeight,
    pub canonical_block_hash: [u8; 32],
    pub object_hash: [u8; 32],
    pub durable_at: KnownTime,
}

pub struct VerifiedManifest {
    pub manifest_id: ManifestId,
    pub object_count: u64,
    pub row_count: u64,
    pub block_range: BlockRange,
    pub manifest_hash: [u8; 32],
    pub previous_manifest_hash: Option<[u8; 32]>,
}

#[derive(Debug, thiserror::Error)]
pub enum ArchiveError {
    #[error("archive I/O failed: {0}")]
    Io(String),
    #[error("manifest verification failed: {0}")]
    ManifestVerification(String),
    #[error("archive range is unavailable")]
    RangeUnavailable,
    #[error("schema fingerprint mismatch")]
    SchemaMismatch,
    #[error("archive object is corrupt: {0}")]
    CorruptObject(String),
}

pub type BlockIterator = Box<dyn Iterator<Item = Result<BlockEnvelope, ArchiveError>> + Send>;

pub trait CanonicalArchive: Send + Sync {
    fn append_block(&self, block: &BlockEnvelope) -> Result<ArchiveReceipt, ArchiveError>;
    fn read_range(&self, chain: &ChainId, range: BlockRange) -> Result<BlockIterator, ArchiveError>;
    fn verify_manifest(&self, manifest: &ManifestId) -> Result<VerifiedManifest, ArchiveError>;
}
```

Production implementation may use local filesystem plus MinIO/S3-compatible replication, but the port exposes no S3 types.

## Stage 1 Exit Criteria

- Approved historical ranges replay contiguously from raw source bytes to canonical archives.
- Every accepted source record is classified; unknown variants are quarantined and observable.
- Spool recovery removes only an incomplete tail and never conceals mid-segment corruption.
- Stable event IDs and content hashes agree across independent sources and machines.
- Gaps stop committed advancement and suppress dependent signals; divergence is reproducible.
- Parquet manifests, source watermarks, and previous-manifest hashes validate.
- JetStream duplicates and acknowledgement loss do not duplicate effects.
- `docs/stage-gates/stage-1-truth-layer.md` is approved and tag `stage-1-truth` exists.
