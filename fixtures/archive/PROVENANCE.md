# Archive Fixture Provenance

`valid-v1/` is a deterministic, fully synthetic local archive generated by:

```sh
cargo +1.97.1 run -p archive-inspect \
  --example generate-archive-fixture --locked --offline -- \
  fixtures/archive/valid-v1
```

It contains no exchange credentials, private keys, personal data, or captured
network traffic. The canonical and raw payloads are fixed test values created
by `tools/archive-inspect/examples/generate-archive-fixture.rs`.

The repository generation gate recreates the complete tree in an isolated
directory, compares every generated byte, verifies the manifest chains, and
independently counts reachable canonical Parquet rows.
